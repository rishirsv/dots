# Drafts voice trial — September 25, 2026

Five independent Luna drafts use the same provisional `VOICE.md`, `STYLE.md`, and user-supplied source passage. Each assignment probes a different subject suggested by, or adjacent to, the source passage. The subjects are hypotheses for testing the profile, not claims about the writer's biography or beliefs.

## Evaluation design

Each draft is a short reflective essay of roughly 280–340 words. Review each against the source sample and the two guides. Score each dimension from 1 (weak) to 5 (strong):

1. **Sentence voice:** natural mix of short landings and longer accumulating sentences; clear spoken diction.
2. **Human grounding:** concrete moments and actions make the idea tangible without inventing the writer's life.
3. **Earned movement:** the piece moves from a recognizable need to an obstacle, stakes, and a payoff that follows.
4. **Restraint and originality:** it avoids borrowed phrases, repetitive rhetorical moves, generic uplift, and overblown promises.
5. **Claim discipline:** consequential claims are sourced, qualified, or framed as possibilities; no false certainty.

The scores are editorial judgments, not measurements of authorship. A strong score says the draft follows the current guide, not that it sounds exactly like the writer. User feedback is the deciding signal for revising the guide.

## Review questions for the writer

- Which piece, if any, sounds most like something you would write?
- Which sentences feel right or wrong, and why?
- Does the voice travel across topics, or only work for vision essays?
- Which proposed rules should be kept, changed, or removed?

The HTML viewer shows the full drafts, a score comparison, review notes, and a feedback form. Feedback is stored locally in the browser and can be downloaded as JSON; it is not sent anywhere automatically.

## First finding

The five drafts follow the guide's concrete, humane side. The bakery piece is closest to the sample's sentence rhythm, though it also repeats the sample's obstacle-to-helper shape. Across topics, the drafts are more cautious and advisory than the source passage's larger imaginative turn. This may mean the guide overweights restraint, or that the assignments elicited a different register. The writer's feedback should settle which explanation is useful before the guide is revised.
