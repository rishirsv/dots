# Examples

Keep a small, curated set of writing examples that show the writing home's rules in action.

- Include positive examples worth learning from and negative examples that reveal recurring misses.
- Prefer full pieces or substantial passages with clear provenance.
- In `VOICE.md` or `STYLE.md`, name the exact rule each example demonstrates.
- Treat examples as evidence, not copy to imitate. Never reuse published language verbatim.
- Remove examples that no longer represent the writing.

Current sources: `agency-passage.md` is the user-supplied voice sample. `dan-shipper-reading-list.md` links to external essays used as technique references for the v2 trial; it does not make those essays part of the user's identity or store their full text.
