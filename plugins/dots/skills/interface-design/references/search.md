# Search

Decide what can be searched and where results belong before placing the field.
Use a global entry for app-wide discovery and a field beside a collection for
local filtering. Keep the scope apparent in placement and wording.

Distinguish an exploratory search landing page from immediate text entry.
For native presentation, read [Apple guidance](platforms/apple.md).

On iPad and Mac, use a toolbar field for search across split-view columns or
results in the detail area; a sidebar field searches that sidebar's content.
A dedicated destination suits app-wide discovery. On iPhone, consider bottom
search placement for reachability. Distinguish a discovery tab from an entry
that immediately opens the keyboard; cancellation should dismiss keyboard input.

Provide useful recent queries with removal controls. Keep predictive suggestions
visually distinct from entered text and subordinate to results. Offer relevant,
visible filters; tokens may supplement them. Show a deliberate no-results state
with the query and a recovery path.

Exercise entry, clearing, cancellation, scope changes, suggestions, filters,
results and no results through [interaction.md](interaction.md).
