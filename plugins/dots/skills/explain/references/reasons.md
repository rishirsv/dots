# Explain rationale

Collect evidence before narrative. Never pick a story and recruit the evidence
that fits it.

Start with the governing instruction or record. Search the smallest useful set
of named files, commits, pull requests, issues, decisions, or discussions. Code
proves behavior, not intent. Expand only when the evidence is incomplete or the
claim warrants it.

Lead with the practical reason or governing constraint. If broader guidance
conflicts with the governing source, state the conflict instead of silently
replacing the premise.

For each material claim:

- Prefer the exact quote and citation over a smooth paraphrase, and make each
  direct claim easy to verify.
- Label inference and name the evidence supporting it.
- Present competing explanations only when evidence supports more than one.
- State contradictions, unavailable sources, and unresolved unknowns.

When another explanation could change the answer, identify the evidence it
would predict and check the highest-value available source. Keep the structure
light; use a compact causal map or comparison table when it helps.
