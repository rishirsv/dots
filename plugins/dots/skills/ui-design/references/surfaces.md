# Choose A Surface Treatment

Use these web treatments when they fit the accepted visual system. Read the
selected recipe for exact values. Preserve structural, selection and focus
boundaries; use system components and materials on native platforms.

- **Nested radii:** read [surface geometry](recipes/surface-geometry.md) when close layers share a visible inset.
- **Unbalanced glyphs or padding:** read [optical alignment](recipes/optical-alignment.md).
- **Depth and elevation:** read [surface depth](recipes/surface-depth.md) when a border represents lift rather than separation.
- **Image edges:** read [image outlines](recipes/image-outlines.md) when content imagery needs separation.
- **Texture or visible gradient banding:** read [noise](recipes/noise.md) when grain produces the intended surface appearance.
